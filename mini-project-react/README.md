# SkyPulse AI 🌤️🌾
### Data-Driven Meteorological Advisory & Agronomic Intelligence System

SkyPulse AI is a modern React application that provides real-time weather forecasts combined with AI-powered agricultural (crop protection, irrigation, fertilizer scheduling) and travel safety recommendations.

---

## ✨ Features

- 🌍 **Real-Time Weather Tracking**: Fetch current weather metrics (temperature, humidity, pressure, wind speed, precipitation) for any city globally via OpenWeather API.
- 📅 **5-Day Meteorological Breakdown**: Aggregated forecast statistics for upcoming days.
- 🚜 **Smart Crop Advisory**: Tailored field guidance for farmers (irrigation timing, fertilizer delay alerts, disease prevention).
- 🚗 **Travel & Commute Safety Radar**: Risk analysis for road travel, hazard highlights, and recommended travel windows.
- 🤖 **Hybrid AI Engine**: Live LLM integration via **Google Gemini API** with an automatic offline rule-based fallback system.
- 🎨 **Modern Dark Glassmorphism UI**: Built with React 19, Vite, and Material UI v7.

---

## 🛠️ Tech Stack

- **Frontend**: React 19, Vite
- **UI Framework**: Material UI (MUI v7), `@emotion/react`
- **APIs**: OpenWeatherMap REST API, Google Gemini AI REST API
- **Deployment**: GitHub Pages

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn

### Installation

1. Clone the repository:
```bash
git clone https://github.com/Nitesh9162/-React_Project-.git
cd mini-project-react
```

2. Install dependencies:
```bash
npm install
```

3. Run the local development server:
```bash
npm run dev
```
Open `http://localhost:5173/` in your browser.

4. Build for production:
```bash
npm run build
```
